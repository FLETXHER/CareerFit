# CareerFit 静态网页部署说明

`careerfit_web/` 是一个纯静态网页项目，只包含 HTML、CSS 和 JS 文件。它可以部署到静态网站托管平台，不需要懂前端，也不需要配置复杂命令。

## 方式 A：Vercel 拖拽部署

1. 打开 Vercel；
2. 登录账号；
3. 选择导入或拖拽部署；
4. 上传 `careerfit_web/` 文件夹；
5. 等待生成网址；
6. 打开网址检查页面是否正常；
7. 将网址放入简历或 BOSS 附件说明。

## 方式 B：Netlify 拖拽部署

1. 打开 Netlify；
2. 登录账号；
3. 找到 Add new site / Deploy manually；
4. 上传 `careerfit_web/` 文件夹；
5. 等待生成网址；
6. 打开网址检查页面是否正常；
7. 将网址放入简历或 BOSS 附件说明。

## 方式 C：暂不部署

如果暂时不部署，可以先使用：

- `careerfit_pdf/CareerFit_AI求职匹配与简历真实性审查工具.pdf`
- `careerfit_long_image/CareerFit_完整长图.png`
- `careerfit_shots/` 里的关键截图

PDF 更适合直接作为 BOSS 附件；网页链接后续再补。

不建议把代码压缩包直接发送给 HR。给 HR 看时，优先使用网页链接、PDF 或关键截图。
